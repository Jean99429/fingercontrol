# fingercontrol

一个独立的实时手指控制视觉拍摄工具项目。它不属于作品集网站代码库。

项目目标：使用摄像头识别 Jean 的指尖与捏合动作，把不同手势映射为文字、声音和实时视觉效果；表演完成后录制为视频，最终作品集只播放剪辑后的成片。

## 当前方向

- 只在最终画面显示指尖追踪点，不显示手腕或完整骨骼。
- 左手使用四个可配置的文字与声音插槽。
- 右手从一套预先实现、效果参数写死的视觉效果库中分配效果。
- 右手只能自定义“哪根手指触发哪个效果”，不在设置页开放 Shader、粒子或动画参数。
- 拇指与食指、中指、无名指、小指的捏合分别触发不同内容。
- 工具可以支持多种效果，但最终首屏视频只选少量动作组成 10–15 秒循环。

视觉效果优先复用或改写成熟的开源 WebGL / Shader 实现，并在采用前核对许可证。最终工具不依赖 Gemini API，也不需要服务器运行效果。
